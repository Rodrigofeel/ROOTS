
# ROOTS

Este site tem como inspiração hospedagens em meio a natureza, o projeto é 100% focado em design e arquitetura. (Projeto Educativo)


## Autores

- [@Rodrigofeel](https://github.com/Rodrigofeel)


## Stack utilizada

**Front-end:** React, Next.js, Typescript, Tailwind CSS, CSS Modules

### IDE

Visual Studio Code

### Ferramenta auxiliar 

Copilot

Claude


## Funcionalidades

- Temas dark e light
- Preview em tempo real
- Modo tela cheia
- Multiplataforma

Este projeto está hospedado na Vercel e utiliza deploy automático através do GitHub.

### Como fazer deploy:

1. **Opção 1: Deploy via Vercel**
https://rootsbr.vercel.app/

2. **Faça fork ou clone do repositório**
```bash
git clone https://github.com/Rodrigofeel/ROOTS.git
```
